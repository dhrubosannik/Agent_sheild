# AgentShield Presentation Design Guide

## Visual Direction

Use a restrained dark cybersecurity interface matching the existing AgentShield console:

- Near-black warm charcoal background
- Thin neutral borders
- IBM Plex Mono for labels and technical values
- Inter for ordinary presentation text
- Small amounts of red, green, amber, and blue only for decisions and status

## Page Treatment

- 16:9 slides
- 12 px or 16 px baseline grid
- Minimal shadows
- Square or 2 px rounded corners
- One primary idea per slide
- Strong section headings
- Consistent footer and slide number

## Architecture Diagrams

Use directional boxes:

1. Agent/Application
2. SDK Wrapper
3. Normalization
4. Inspection
5. Policy Engine
6. Execution Decision
7. Tool or Audit

Keep arrows and labels readable.

## Screenshots

Use only real AgentShield screenshots. Do not invent metrics or hide limitations. Blur or omit identifiers if future demo data changes.

## Typography

- Title: Inter Semibold
- Body: Inter Regular
- Technical labels and code: IBM Plex Mono

## Avoid

- Excessive gradients
- Glowing effects
- Generic AI-brain illustrations
- Large decorative security imagery
- Unsupported claims
- Overloaded code snippets
- Fake screenshots
